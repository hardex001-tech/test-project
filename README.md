# Namaa

Namaa is a lightweight SaaS dashboard concept for small and medium businesses in Dubai. It brings customers, invoices, expenses, and UAE VAT readiness into one calm workspace.

## Run locally

Open `index.html` in a browser. No build step or external dependencies are required.

## Included in this MVP

- Overview dashboard with revenue, receivables, expenses, and VAT status
- Customer directory with search
- Invoice list with status filters
- Expense tracking
- UAE VAT-ready workspace settings
- Responsive layout for desktop and mobile
